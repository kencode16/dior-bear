# DIOR熊漂

可愛的熊熊消消樂網頁遊戲，手機和電腦都能玩；iPhone 可以用 Safari「分享 → 加入主畫面」，像 app 一樣全螢幕玩。

- 主角丁噹熊最喜歡噴香水，帶著寵物狗大不溜，四章「食衣住行」一路收集材料、調出新香水、認識新的熊朋友。
- 40 關、熊掌／蜂巢炸彈／香水瓶與 6 種組合技、雪塊／木箱／毛線團／蜂蜜黏黏、帶熊寶寶回家。
- 用星星幫丁噹熊和大不溜換裝、布置樹洞小屋、收集香水與熊朋友貼紙。
- 沒有體力、沒有廣告、沒有內購；進度存在自己的瀏覽器裡。

美術全部以程式繪製；狗叫聲為 CC0 錄音，出處見 `assets/sounds/CREDITS.txt`。
本作為個人非商業的同人小遊戲，與任何品牌無關。
